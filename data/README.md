# Data setup

No third-party raw recordings/archives or reconstructed700-row feature values are included. Obtain the two datasets from their official records after reviewing applicable terms. See uci/README.md and external/README.md. The external directory contains only the ordered248-feature schema and position/domain metadata needed to reproduce the frozen temporal protocol.

Expected user-created paths are data/uci/Dataset/batch1.dat…batch10.dat and data/external/Dataset/ containing the official notebook plus Day folders. Derived outputs belong in a separate new out/ directory. Do not mix the128-feature UCI dataset with its concentration-extended variant. Do not alter or delete the retained Batch2samples.
